# 2026-11-16 — Cara GitHub menghitung kotak hijau

Kotak hijau di profil GitHub bukan dihitung dari semua commit — ada aturannya:

- Commit harus masuk ke **default branch** (biasanya `main`) atau `gh-pages`.
- Email author commit harus **terhubung ke akun GitHub** yang sama.
- Commit ke branch lain yang belum di-merge **tidak dihitung**.
- Commit di repo privat tetap dihitung, tapi hanya terlihat sebagai kotak tanpa detail kalau pengaturan privasinya begitu.

Jadi kalau mau hijau terus: satu commit ke `main` setiap hari, dengan email yang benar. Repo ini dibuat untuk itu — satu catatan belajar per hari, commit langsung ke `main`.
