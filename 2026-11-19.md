# 2026-11-19 — Jangan bagi sebelum kali: presisi di Solidity

Solidity tidak mengenal bilangan desimal — semua pembagian bilangan bulat
dibulatkan **ke bawah**, dan sisa pembagiannya hilang selamanya.

```solidity
// SALAH: 5 / 2 = 2, lalu 2 * 100 = 200 (kehilangan 50!)
uint salah = (5 / 2) * 100;

// BENAR: 5 * 100 = 500, lalu 500 / 2 = 250
uint benar = (5 * 100) / 2;
```

Contoh nyata: menghitung bagian fee `amount * feeBps / 10000`. Kalau dibalik
jadi `amount / 10000 * feeBps`, fee untuk amount kecil jadi **nol** — dan
penyerang bisa mengeksploitasi pembulatan ini dengan banyak transaksi kecil
(serangan "dust").

Aturan praktisnya: **kali dulu, bagi belakangan**, dan untuk token dengan
desimal berbeda, samakan dulu skalanya (misalnya ke 18 desimal) sebelum
menghitung. Kalau hasil akhirnya harus dibulatkan, bulatkan ke arah yang
menguntungkan protokol, bukan pengguna.
