# 2026-11-28 — Jangan asumsikan transfer token selalu berhasil: cek return value

Tidak semua token ERC20 me-revert saat transfer gagal. Beberapa token
(misalnya USDT) mengembalikan `false` tanpa revert, dan ada juga token yang
tidak mengembalikan apa-apa. Kalau kontrakmu memanggil `token.transfer(...)`
tanpa mengecek hasilnya, kontrak akan mengira dana sudah terkirim padahal
tidak — catatan saldo jadi tidak sinkron dengan saldo sebenarnya.

```solidity
// BERBAHAYA: gagal diam-diam, saldo dicatat seolah sudah dibayar
token.transfer(user, amount);
paid[user] = true; // padahal transfer bisa saja gagal

// AMAN: pakai SafeERC20, yang revert kalau transfer gagal
using SafeERC20 for IERC20;
token.safeTransfer(user, amount);
paid[user] = true;
```

Aturan praktisnya: jangan pernah memanggil `transfer` / `transferFrom`
mentah pada token yang tidak kamu kontrol. Pakai `SafeERC20` dari
OpenZeppelin, yang menangani token yang mengembalikan `false` maupun token
yang tidak mengembalikan nilai sama sekali. Saat audit, cari semua panggilan
transfer mentah — terutama di fungsi payout, refund, dan withdraw — lalu
tanya: kalau transfer ini gagal diam-diam, state apa yang sudah terlanjur
berubah?
